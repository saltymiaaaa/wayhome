# Project Summary
A browser-based interactive 3D world and simulation project. Users can set up and explore a simulated environment, with supporting guide, inbox, and 3D viewing features.

# Project Module Description
- **World and simulation:** `world.js` defines the environment; `sim.js` handles simulation behavior.
- **3D viewing and visuals:** `watch3d.js` provides 3D viewing features, `art.js` manages artwork, and `icons.js` provides icons. `vendor/three.min.js` supplies Three.js.
- **Setup and guidance:** `setup.js` handles setup flows, while `guide.js` provides guidance.
- **Inbox:** `inbox.js` manages inbox-related functionality.
- **Localization:** `i18n.js` and `i18n_id.js` provide localization support, including Indonesian translations.
- **Application startup:** `boot.js` initializes the app, and `app.js` coordinates application behavior.
- **Presentation:** `index.html` provides the page structure and `css/style.css` defines its styling.
